# Dead House: Last Light

A browser-based, first-person zombie survival game. Hold a four-room house against incoming waves, earn scrap from kills and cleared waves, and spend it at the supply cabinet between fights.

This is a **reconstruction** from the available design description. The earlier playable version was not present in the supplied repository or workspace; the initial repository contained only this README and `.gitignore`. It is not a modification of that missing build.

## Run

Use a desktop browser with WebGL and pointer lock (Chromium is the primary target). No package installation or external asset download is needed. From the project directory run:

```sh
python3 -m http.server 8000
```

Visit `http://localhost:8000` in the browser and click **Enter the House**. Keep the terminal running while playing; stop the server with Ctrl+C. A local HTTP server is required for the JavaScript modules; opening `index.html` directly has not been validated. Browser audio starts after a user gesture and is optional.

## Controls

| Input | Action |
| --- | --- |
| W / A / S / D | Move |
| Mouse | Look |
| Left click | Fire pistol; click the game view to capture the mouse |
| Right mouse button | Aim |
| Shift | Sprint while moving forward (uses stamina) |
| R | Reload |
| Q | Switch between owned weapons |
| E | Open or close the supply cabinet; repair the barricade when nearby |
| Esc | Pause or close the stash |

Adjust sensitivity in the title or pause menu. The slider is in degrees per mouse movement unit, defaults to 0.10°, and is remembered when browser storage is available. The mouse is captured for play and released for menus, loss of focus, and game over. Resume to capture it again.

## Surviving

The first wave follows a short preparation period. Walkers are joined by faster, lower-health runners in later waves. Aim high for extra damage and rewards. Killing enemies and clearing waves earns scrap; find the supply cabinet in the garage to buy ammunition, healing, a pump shotgun, damage upgrades, a larger magazine, or speed. The $550 shotgun arrives with six shells loaded and 24 in reserve; ammunition purchases refill the currently equipped weapon. Some upgrades have a maximum level. Waves are separated by a short restocking period, but the stash can be used during a wave too. Reinforce the boarded doorway between the living room and bedroom for $100 per board, up to three; enemies can break it.

## Project layout and credits

- `index.html`, `styles.css`, `src/ui.js` — menu, HUD and controls.
- `src/game.js` — input, combat, movement, wave logic, AI and audio.
- `src/world.js` — procedural house, props, weapons and enemy geometry.
- `vendor/three.module.js` — locally bundled Three.js; see `vendor/THREE-LICENSE.txt` for its MIT license.

The game geometry and synthesized audio are generated by the project and require no remote assets. The current implementation is a compact reconstruction: there are no unlockable rooms yet. Game feel and balancing still benefit from human playtesting.
